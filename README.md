# แดชบอร์ดอุตสาหกรรมเครื่องจักรกลและโลหะการ

**ผู้จัดทำ:** นายภูริพัฒน์ ตานน้อย  
**รหัสนิสิต:** 67160230

## ที่มาและเป้าหมาย

โครงงานนี้นำข้อมูลดัชนีผลผลิตอุตสาหกรรมรายเดือนมาทำเป็น แดชบอร์ด เพื่อช่วยให้ผู้ชมเห็นแนวโน้มและเปรียบเทียบผลิตภัณฑ์ในกลุ่มเครื่องจักรกลและโลหะการได้ง่ายขึ้น

แดชบอร์ด ใช้เพื่อสำรวจแนวโน้มประกอบการติดตาม ไม่ได้ใช้แทนข้อมูลคำสั่งซื้อ ต้นทุน กำลังการผลิต หรือคำแนะนำทางธุรกิจโดยตรง

## ไฟล์ในโครงงาน

- `index.html` — หน้า แดชบอร์ด เปิดและใช้งานตัวกรอง กราฟ และตารางได้
- `ชุดข้อมูลแดชบอร์ด.csv` — ข้อมูลที่คัดเลือกและแปลชื่อคอลัมน์เป็นภาษาไทย
- `README.md` — คำอธิบายโครงงาน วิธีเปิด และข้อจำกัด

## วิธีเปิด

เปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์ แล้วเลือกปี หมวดอุตสาหกรรม หรือสินค้า กราฟและตารางจะปรับตามตัวกรอง

กราฟใช้ไลบรารี ชุดคำสั่งสร้างกราฟจากอินเทอร์เน็ต จึงต้องเชื่อมต่ออินเทอร์เน็ตขณะเปิดหน้า แดชบอร์ด

## ชุดข้อมูล

- แหล่งข้อมูลต้นทาง: สำนักงานเศรษฐกิจอุตสาหกรรม, ดัชนีผลผลิตอุตสาหกรรม
- ไฟล์ต้นทางที่ใช้: `Prodidx2_E_open.csv`
- ช่วงข้อมูลในชุดที่คัดเลือก: มกราคม 2021 ถึง สิงหาคม 2026
- ขอบเขตที่เลือก: 27 สินค้าในหมวดเหล็กและโลหะ ผลิตภัณฑ์โลหะแปรรูป อุปกรณ์ไฟฟ้า และเครื่องจักร
- จำนวนข้อมูลหลังคัดเลือก: 1,836 แถว
- หนึ่งแถวแทนข้อมูลของสินค้า 1 รายการใน 1 เดือน

การเลือก 27 รายการเป็นการกำหนดขอบเขตให้เหมาะกับโครงงาน ไม่ได้ครอบคลุมทุกผลิตภัณฑ์ที่เกี่ยวข้องกับอุตสาหกรรมนี้

## วิธีอ่านตัวเลข

- **ดัชนีผลผลิต:** ใช้ดูทิศทางการเปลี่ยนแปลงของผลผลิต ไม่ใช่จำนวนชิ้นหรือมูลค่าผลผลิต
- **เปลี่ยนจากเดือนก่อน:** เปรียบเทียบกับเดือนที่อยู่ก่อนหน้าทันที
- **เปลี่ยนจากปีก่อน:** เปรียบเทียบกับเดือนเดียวกันของปีก่อน
- **ดัชนีภาพรวม:** เมื่อเลือกหลายสินค้า จะแสดงค่าเฉลี่ยโดยใช้น้ำหนักความสำคัญจากข้อมูลต้นทาง ไม่ได้นำค่าดัชนีมาบวกกัน
- **ปี 2026:** ในไฟล์นี้มีข้อมูลถึงเดือนสิงหาคม จึงยังไม่ใช่ข้อมูลครบทั้งปี

## ตัวอย่างข้อค้นพบ

ในหมวดอุปกรณ์ไฟฟ้า เดือนสิงหาคม 2026 สายเคเบิลมีดัชนีผลผลิตสูงกว่าเดือนเดียวกันของปีก่อน 54.62% ตามข้อมูลชุดที่คัดเลือก ขณะที่สายไฟฟ้าเพิ่มขึ้น 11.12% ควรใช้ตัวเลขนี้เป็นสัญญาณให้ติดตาม และพิจารณาข้อมูลธุรกิจอื่นประกอบ
